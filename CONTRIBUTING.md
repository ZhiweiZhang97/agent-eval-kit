# Contributing

Thanks for contributing to Agent Eval Kit.

1. Fork the repository and create a feature branch.
2. Install development dependencies with `pip install -e ".[dev]"`.
3. Add tests for changes.
4. Run `ruff check .` and `pytest -q`.
5. Open a pull request describing the problem, approach, and test coverage.

Please keep contributions focused. For large features, open an issue first so the design can be discussed publicly.
